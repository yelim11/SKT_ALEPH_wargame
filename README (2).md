# LOST//SIGNAL — STAGE 1

브라우저 기반 픽셀아트 워게임 프로토타입입니다.

## 실행
- GitHub Pages: 저장소 루트 `index.html` (main 브랜치, `/`)
- 로컬 실행: `index.html` 파일 열기 (상대 경로 `assets/` 유지)

## 조작
WASD / 방향키: 이동 · Shift: 달리기 · Space: 점프 · Z: 앉기 · E: 조사/줍기 · I/Tab: 인벤토리 · Q/C: 일반 공격. F/X 스킬은 STAGE 3에서 해금 전까지 잠김.

## 콘텐츠
Stage 1 도시 자유 탐색, 10개 퍼즐, 이동형 아이템 4종, 고정형 장비 6종. 현재 FLAG 검증과 DB 기록은 로컬 시뮬레이션이며 실제 서버와 연결되지 않았습니다.

## 공개 전 주의
공개된 `index.html`에 포함되는 정답/FLAG를 실제 보안 검증에 사용하면 안 됩니다. 운영용 문제는 서버에서 검증하세요.
