# LOST//SIGNAL · STAGE 1

탑뷰 픽셀아트 탐험형 워게임 데모.

## 실행
GitHub Pages: https://yelim11.github.io/SKT_ALEPH_wargame/
루트 index.html을 실행합니다. 26개 이미지 데이터 청크 파일을 함께 유지해야 합니다.

## 조작
WASD/방향키 이동, Shift 달리기, Space 점프, Z 앉기, E 조사/획득, I/Tab 인벤토리, Q/C 공격. F/X 스킬은 3스테이지 전까지 잠금입니다.

## 상태
문제 01–10 및 휴대용 디바이스 수집. 현재는 로컬 시뮬레이션 데모이며 서버 측 FLAG 검증과 DB는 미연결입니다. 클라이언트에 실습용 정답이 포함되어 있어 실제 보안 채점 서버로 쓰면 안 됩니다.

## 저작권
사용 중인 Graffiti Artist 스프라이트 및 기타 이미지 에셋은 공개 게시 권한을 확인해야 합니다.
