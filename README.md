# STAGE 1 — 버려진 도시

최신 LOST//SIGNAL 픽셀 도시 데모. 

## 실행하기

- 이 GitHub 저장소 전체를 ZIP으로 다운로드한 뒤 **stage1/index.html**을 크롬에서 엽니다.
- `asset-packs/` 폴더는 원본 PNG 픽셀 에셋과 배경을 포함한 실행 데이터입니다. HTML과 같은 상대 경로로 반드시 함께 유지하세요.
- GitHub Pages를 활성화한 경우 `/stage1/` 경로에서도 실행할 수 있습니다. Pages 설정은 별도입니다.

## 게임 내용

탑뷰 자유 탐험, 이동/달리기/점프 물리, Z 앉기, Q/C 기본 공격, I/Tab 가방, E 수집·조사, 모바일 조작, 픽셀 기기별 UI 및 워게임 문제 1~10.

휴대용 아이템(휴대폰·워치·USB·카메라)은 수집 후 어디서나 분석할 수 있고, 고정형 장비는 현장에서 조사합니다.
**F/X는 3스테이지 미션 보상 전까지 잠금입니다.** Stage 1에서 어떤 문제를 풀어도 스킬이 열리지 않습니다.

> 현재 브라우저 로컬 저장 및 오프라인 실습 시뮬레이션입니다. 실제 서버 측 FLAG 검증과 외부 DB 연결은 아직 구현하지 않았습니다. 다른 팀원 DB와는 데이터베이스를 분리하고, 스키마 계약만 공유하기로 한 구성을 따릅니다.

## 구조

- `index.html` — 게임 HTML, 스타일, 논리 (읽고 수정 가능)
- `asset-packs/pack-00.js` ~ `pack-14.js` — 원본 픽셀 이미지 내장 데이터 (15개, 순서대로 로드)

이미지 데이터는 GitHub 업로드 크기 제한을 피하기 위해 분리했으며, HTML 시작 시 메모리에서 이미지 URL로 결합합니다. 동일한 최신 로컬 단일 HTML 데모의 기능을 유지합니다.
